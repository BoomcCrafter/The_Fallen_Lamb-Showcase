A dark fantasy action RPG developed under the name **RevelationArc**, featuring dynamic combat, randomized gameplay elements, character progression, and challenging encounters.

## About the Game

The Fallen Lamb is a 2D action RPG with roguelike elements, where each run offers different challenges and opportunities.

Players can collect upgrades, combine abilities, develop their character, and make decisions that affect their journey.

The game combines fast-paced combat, randomized mechanics, and a dark fantasy atmosphere.

## Development Process

The Fallen Lamb is an independent game development project created with the assistance of AI tools.

My work included developing the game concept, implementing and modifying gameplay systems, integrating features, testing, debugging, and preparing the game for publication.

The programming process combined code written independently with code generated or supported by AI tools.

AI was used as a development assistant, while project decisions, integration, testing, and the final direction of the game remained under my control.
